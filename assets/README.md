# Lumi visual assets

These image assets are cropped from the original Lumi brand sheet supplied for this project. They are not newly generated mascot variations.

- `lumi-app-icon.png`: application/window icon crop.
- `lumi-tray-icon.png`: small tray icon crop for future system-tray integration.

The current build bundles the assets so the application icon is available in source runs and packaged builds. The Windows notification-area integration will be wired when the tray feature is implemented.
