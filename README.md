**Lumi — твоя умная помощница.** Персональное Windows-приложение с локальными заметками и планируемой поддержкой локального ИИ и Discord.

> Проект находится на ранней стадии. Сейчас реализована базовая оболочка Windows и локальные заметки. Локальная языковая модель, менеджер моделей и Discord-бот ещё не подключены.

## Идея проекта

- **Локальные заметки:** записи хранятся в SQLite на компьютере пользователя.
- **Локальный ИИ:** планируется встроенный движок на базе llama.cpp и GGUF-моделей, без обязательной установки Ollama или LM Studio.
- **Менеджер моделей:** планируется каталог моделей, загрузка и проверка совместимости с памятью компьютера.
- **Discord:** планируется отдельный модуль бота, использующий общие заметки с разрешения пользователя.
- **Windows:** планируется сборка приложения и установщика через GitHub Actions.

## Запуск из исходного кода

Требуется Python 3.11 или новее.

```powershell
py -3.12 -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m lumi
```

Запуск тестов:

```powershell
python -m pytest
```

## Где хранятся данные

В Windows база заметок находится в:

```text
%LOCALAPPDATA%\\Lumi\\data\\lumi.db
```

Папка с данными отделена от исходников и будущей установки приложения, чтобы обновление программы не удаляло заметки.

## Сборка и установка Windows

Workflow **Windows build** запускается при push или pull request в `main`, а также вручную через вкладку **Actions**. Он запускает тесты и публикует артефакт `Lumi-Windows`.

Чтобы собрать установщик и создать GitHub Release, нужно опубликовать тег версии, например `v0.1.0`. Workflow соберёт `Lumi-Setup-0.1.0.exe` и файл `SHA256SUMS.txt` с контрольной суммой. Установщик проверяет совместимость с 64-разрядной Windows 10 или новее, устанавливает собранное приложение и создаёт ярлык в меню «Пуск». Python отдельно устанавливать не нужно: приложение и его Python-зависимости включаются в сборку PyInstaller. База заметок хранится отдельно в `%LOCALAPPDATA%\\Lumi\\data\\lumi.db` и не должна удаляться при обновлении.

**Важно:** автоматическая проверка обновлений при каждом запуске приложения пока не реализована. Следующий этап — отдельный updater, проверка версии на GitHub, проверка SHA-256 и показ списка изменений. Движок ИИ и модель пока не включены.

## Минимальные целевые требования

- Windows 10/11, 64-bit
- Python 3.11+ только для запуска из исходников; конечному пользователю Python не потребуется после сборки
- Для текущей версии заметок: обычный современный ПК
- Для будущей локальной модели: ориентир 16 ГБ оперативной памяти; видеокарта с 6 ГБ VRAM желательна, но совместимость будет зависеть от выбранной модели и квантования

## Безопасность

- Не добавляйте токены Discord, пароли, личные заметки, базы данных или файлы моделей в Git.
- Токен Discord будет храниться локально через защищённое хранилище Windows или переменную окружения.
- Скачанные модели будут проверяться перед использованием.
