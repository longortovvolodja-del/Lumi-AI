**Lumi — твоя умная помощница.** Windows-приложение с локальными заметками и планами по развитию локального ИИ.

**Проверенная версия: v0.1.8. Публичный стабильный выпуск: v0.1.6.** Готовые сборки и установщики публикуются в [GitHub Releases](https://github.com/longortovvolodja-del/Lumi-AI/releases/latest).

> Проект развивается. В текущей версии доступны графическая оболочка Windows и локальные заметки. Локальный ИИ, менеджер моделей и Discord-бот пока находятся в разработке.

## Возможности и планы

- **Локальные заметки:** записи хранятся в базе SQLite на компьютере пользователя.
- **Локальный ИИ:** планируется встроенный движок на базе llama.cpp и GGUF-моделей без обязательной установки Ollama или LM Studio.
- **Менеджер моделей:** планируется загрузка моделей и проверка совместимости с компьютером.
- **Discord:** планируется отдельный модуль бота с доступом к заметкам только с разрешения пользователя.
- **Windows:** приложение собирается автоматически; готовые версии доступны в GitHub Releases.

## Установка

1. Откройте страницу [последних релизов Lumi AI](https://github.com/longortovvolodja-del/Lumi-AI/releases/latest).
2. Скачайте установщик из раздела **Assets** выбранного релиза.
3. Запустите установщик и следуйте инструкциям на экране.

Для обычной установки готовой сборки **не нужно отдельно устанавливать Python**, создавать виртуальное окружение или запускать команды в терминале.

Если нужен конкретный выпуск, откройте [все версии Lumi AI](https://github.com/longortovvolodja-del/Lumi-AI/releases) и выберите нужный релиз. Публичная стабильная версия проекта пока **v0.1.6**. Версия **v0.1.8** проверена в тестовой установке; после объединения изменений и проверки сборки её можно будет выпустить как стабильный GitHub Release.

## Где хранятся данные

В Windows база заметок находится в:

```text
%LOCALAPPDATA%\\Lumi\\data\\lumi.db
```

Пользовательские данные хранятся отдельно от файлов приложения. При обновлении приложения заметки должны сохраняться. Не удаляйте эту папку вручную, если хотите сохранить свои записи.

## Автоматическая сборка и обновления

Сборка Windows-приложения и установщика выполняется с помощью GitHub Actions. Готовые файлы публикуются в [GitHub Releases](https://github.com/longortovvolodja-del/Lumi-AI/releases).

В приложении пока нет автоматического обновления при каждом запуске. Чтобы установить новую версию, проверьте страницу релизов и скачайте актуальный установщик.

## Системные требования

- Windows 10 или новее, 64-разрядная версия.
- Для установки готовой сборки Python отдельно не требуется.
- Для будущих локальных ИИ-моделей требования к оперативной памяти и видеокарте будут зависеть от выбранной модели.

## Безопасность

- Не добавляйте токены Discord, пароли, личные заметки, базы данных или файлы моделей в Git.
- Если будет добавлен Discord-бот, его токен должен храниться локально безопасным способом.
- Перед использованием скачанных моделей следует проверять их источник и целостность.
